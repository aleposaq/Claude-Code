# Educational Agent

An AI-powered educational agent — a tutor that teaches, guides, and adapts to
the learner instead of just answering questions.

> 🚧 **Early days.** This repository is a fresh starting point; the sections
> below are scaffolding to fill in as the project takes shape.

## What it will do

- Hold a teaching conversation: explain concepts, check understanding, and
  adjust difficulty based on the learner's responses.
- Guide rather than solve: nudge the learner toward the answer with hints and
  Socratic questions instead of handing over solutions.
- Track progress across sessions so lessons build on each other.
